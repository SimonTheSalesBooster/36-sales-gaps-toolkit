# /incumbent-displacer -- Incumbent Vendor Displacement

## Why This Skill Exists

Client Gap #9 (the client uses multiple vendors delivering services similar to ours) is usually mishandled by competing on a features list. The canonical mitigation is specific: find out what isn't working with the incumbent, and position specifically around that gap, not around features. This skill builds that repositioning.

## Step 1 -- Get Deal Context

Ask (if not already given): "Who's the incumbent, what do you know (or can find out) about what isn't working with them, and what has the client already said, directly or indirectly, about their frustration with the current vendor?"

If nothing is known yet about the incumbent's shortfall, write the specific discovery questions needed to surface it -- do not guess or assume a generic weakness. Example structure: "What made you start looking at other options?" / "If [incumbent] were perfect, would we be having this conversation?" / "What's the one thing you wish they did differently?"

## Step 2 -- Name the Specific Gap

Once the incumbent's actual shortfall is known, state it in one sentence, in the client's own language if possible -- not "they're not good enough" but the specific, concrete failure (a missed deadline pattern, a support gap, a feature that doesn't exist, a relationship that went cold).

## Step 3 -- Build the Positioning Angle

Write positioning language that is built entirely around the named gap, not a features comparison:

```
Do NOT: "We offer X, Y, Z features the incumbent doesn't have."
DO: "You mentioned [specific incumbent failure]. Here's specifically how we handle that: [concrete answer tied to the exact gap named]."
```

Never disparage the incumbent by name or imply the client made a bad choice going with them -- the client chose them for real reasons at the time. The angle is "here's what changed" or "here's the specific gap," not "you chose wrong."

## Step 4 -- Reference Check Offer

If reputational risk (Client Gap #12) is also a factor, pair this with a reference offer: let the client talk to 2-3 past clients directly, unscripted, so the displacement claim is verifiable rather than just asserted.

## Integration

- Direct mitigation for Client Gap #9 -- run `/client-gap-check` or `/gap-scan` first to confirm.
- If Team Gap #7 (RFP-driven, no direct buyer conversation) is also present, this skill's discovery questions only work once a real conversation with the buyer exists -- get out of the RFP paper process first.
- Never talk down to the client for their current vendor choice -- indict the specific gap in what happened, never their judgment.
